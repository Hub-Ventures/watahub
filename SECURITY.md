# Security Policy

## Supported versions

Only the latest released version of Watahub receives security fixes. If you run an older version, upgrade to the latest release to get them.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**, or go to <https://github.com/Hub-Ventures/watahub/security/advisories/new>.

Please do not open a public issue, pull request or discussion for a vulnerability.

## Response

Hub Ventures handles the reports and acknowledges each one within 72 business hours.
