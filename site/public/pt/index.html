O hub dos seus agentes para WhatsApp

Gateway open source para a API do WhatsApp Cloud, feito para agentes que trabalham para o seu negócio: suporte, vendas, reservas. MIT, no Cloudflare Workers ou Node.

  1. 1

    Conecte sua linha O Embedded Signup conecta o número. O token do negócio fica no gateway.

  2. 2

    Implante seus agentes na sua linha Seu agente recebe cada mensagem como um webhook assinado e responde com POST /v1/messages.

  3. 3

    Pronto! Entregas com falha são reenviadas e, na conta hospedada, uma pessoa pode responder pelo Inbox.

Conecte sua linha

Quatro valores da Meta no gateway. Uma vez só.

App ID
META_APP_IDO app da Meta dono do webhook.
App Secret
META_APP_SECRETTroca o código do Embedded Signup. Quem chama não pode enviá-lo.
Configuration ID
META_CONFIGURATION_IDO config_id do Embedded Signup para o FB.login.
API version
META_API_VERSIONA versão da Graph API. Padrão v24.0.

Envie o código, o id da WABA, o id do número e o PIN. O gateway conclui a linha.

O que o connect faz

  1. Troca o código do Embedded Signup.
  2. Guarda o token do negócio para esse id de número.
  3. Inscreve a WABA nas mensagens.
  4. Registra o número com o PIN de 6 dígitos.

POST /v1/onboarding/connect 

curl -X POST "$GATEWAY/v1/onboarding/connect" \
  -H "Authorization: Bearer $WATAHUB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "AQD...embedded-signup-code",
    "wabaId": "105555123456789",
    "phoneNumberId": "100609346426000",
    "pin": "581063"
  }'

Sem accessToken A resposta não inclui o token do negócio.

$GATEWAY é o host onde você implanta o Watahub. watahub.dev é só a página do projeto.

Implante seus agentes na sua linha

Seu agente recebe cada mensagem recebida como um webhook assinado e responde com POST /v1/messages. Ele informa o id do número; o Watahub usa o token que guardou. Você não o envia.

Um só endpoint para texto, templates, mídia e mensagens interativas. A mídia sobe para a Meta em streaming, até 100 MB.

O que você nunca toca

O connect faz cada uma dessas coisas quando conclui a linha.

  • Token de usuário do sistema

    O connect guarda um token do negócio para cada id de número.

    Feito pelo connect

  • Inscrever a WABA

    O connect inscreve a WABA nas mensagens.

    Feito pelo connect

  • Registrar o número

    O connect o registra com o PIN de 6 dígitos.

    Feito pelo connect

Os eventos chegam planos e assinados

A Meta envia para /webhook. O Watahub verifica o X-Hub-Signature-256, achata o envelope da Meta e encaminha uma entrega assinada para o seu endpoint.

  • Mensagens

    text, image, audio, video, document, location, contacts, reaction, interactive

  • Ecos

    Respostas enviadas pelo app WhatsApp Business.

  • Status

    sent, delivered, read, failed

Verifique a assinatura com o seu segredo e deduplique pelo x-watahub-delivery-id.

Rode você mesmo

MIT. Um operador: um app da Meta, um webhook assinante, uma chave de API e as linhas que você conectar. Você paga as tarifas da Meta direto, sem acréscimo.

  • Cloudflare Workers

    O gateway é o próprio Worker. Esta página não é esse Worker.

  • Node

    As mesmas rotas. pnpm run dev:node.

  • Um webhook assinante

    A Meta envia para /webhook; você recebe uma entrega assinada e normalizada.

Ou dispense o app da Meta

Crie uma conta em app.watahub.dev e conecte seus números com o Embedded Signup. O token da Meta fica selado no gateway; você tem uma chave de API do Watahub que pode revogar.

  • Inbox: leia, responda e atribua conversas.
  • Webhooks por número, assinados com o seu segredo.
  • Logs de chamadas à API, à Meta e de entregas, guardados por 7 dias.
  • Chaves de API exibidas uma vez e revogáveis.
  • Instalável no computador e no celular, com notificações push de novas mensagens.
