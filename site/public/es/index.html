El hub de tus agentes para WhatsApp

Gateway open source para la API de WhatsApp Cloud, hecho para agentes que trabajan para tu negocio: soporte, ventas, reservas. MIT, en Cloudflare Workers o Node.

  1. 1

  3. 3

Conecta tu línea

Cuatro valores de Meta en el gateway. Una sola vez.

App ID
META_APP_IDLa app de Meta dueña del webhook.
App Secret
META_APP_SECRETCanjea el código de Embedded Signup. Quien llama no puede enviarlo.
Configuration ID
META_CONFIGURATION_IDEl config_id de Embedded Signup para FB.login.
API version
META_API_VERSIONLa versión de Graph. Por defecto v24.0.

Envía el código, el id de la WABA, el id del número y el PIN. El gateway termina la línea.

Qué hace connect

  1. Canjea el código de Embedded Signup.
  2. Guarda el token del negocio para ese id de número.
  3. Suscribe la WABA a los mensajes.
  4. Registra el número con el PIN de 6 dígitos.

$GATEWAY es el host donde despliegas Watahub. watahub.dev es solo la página del proyecto.

Despliega tus agentes en tu línea

Tu agente recibe cada mensaje entrante como un webhook firmado y responde con POST /v1/messages. Nombra el id del número; Watahub usa el token que guardó. Tú no lo pasas.

Un solo endpoint para texto, plantillas, media y mensajes interactivos. La media sube a Meta en streaming, hasta 100 MB.

Lo que nunca tocas

Connect hace cada una de estas cosas cuando termina la línea.

  • Token de usuario del sistema

    Connect guarda un token del negocio para cada id de número.

    Lo hace connect

  • Suscribir la WABA

    Connect suscribe la WABA a los mensajes.

    Lo hace connect

  • Registrar el número

    Connect lo registra con el PIN de 6 dígitos.

    Lo hace connect

Los eventos llegan planos y firmados

Meta publica en /webhook. Watahub verifica X-Hub-Signature-256, aplana el sobre de Meta y reenvía una entrega firmada a tu endpoint.

  • Mensajes

    text, image, audio, video, document, location, contacts, reaction, interactive

  • Ecos

    Respuestas enviadas desde la app WhatsApp Business.

  • Estados

    sent, delivered, read, failed

Verifica la firma con tu secreto y deduplica por x-watahub-delivery-id.

Córrelo tú mismo

MIT. Un operador: una app de Meta, un webhook suscriptor, una clave API y las líneas que conectes. Pagas las tarifas de Meta directo, sin recargo.

  • Cloudflare Workers

    El gateway es su propio Worker. Esta página no es ese Worker.

  • Node

    Las mismas rutas. pnpm run dev:node.

  • Un webhook suscriptor

    Meta publica en /webhook; tú recibes una entrega firmada y normalizada.

O sáltate la app de Meta

Crea una cuenta en app.watahub.dev y conecta tus números con Embedded Signup. El token de Meta queda sellado en el gateway; tú tienes una clave API de Watahub que puedes revocar.

  • Inbox: lee, responde y asigna conversaciones.
  • Webhooks por número, firmados con tu secreto.
  • Logs de llamadas al API, a Meta y de entregas, guardados 7 días.
  • Claves API que se muestran una vez y se pueden revocar.
  • Se instala en escritorio y teléfono, con avisos push de mensajes nuevos.
