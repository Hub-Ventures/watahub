Connect your line

Four Meta values on the gateway. Once.

App ID
META_APP_IDThe Meta app that owns the webhook.
App Secret
META_APP_SECRETExchanges the Embedded Signup code. Callers cannot send it.
Configuration ID
META_CONFIGURATION_IDThe Embedded Signup config_id for FB.login.
API version
META_API_VERSIONThe Graph API version. Default v24.0.

Send the code, the WABA id, the phone number id and the PIN. The gateway finishes the line.

What connect does

  1. Exchanges the Embedded Signup code.
  2. Stores the business token for that phone number id.
  3. Subscribes the WABA to messages.
  4. Registers the phone with the 6-digit PIN.

POST /v1/onboarding/connect 

curl -X POST "$GATEWAY/v1/onboarding/connect" \
  -H "Authorization: Bearer $WATAHUB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "AQD...embedded-signup-code",
    "wabaId": "105555123456789",
    "phoneNumberId": "100609346426000",
    "pin": "581063"
  }'

Response 200 

{
  "phoneNumberId": "100609346426000",
  "wabaId": "105555123456789",
  "subscribed": true,
  "registered": true
}

No accessToken The response does not include the business token.

$GATEWAY is the host where you deploy Watahub. watahub.dev is only the project page.

Deploy your agents on your line

Your agent gets every inbound message as a signed webhook and replies with POST /v1/messages. It names the phone number id; Watahub uses the token it stored. You don't pass it.

One endpoint for text, templates, media and interactive messages. Media uploads stream to Meta, up to 100 MB.

What you never touch

Connect does each of these when it finishes the line.

  • System user token

    Connect stores a business token for each phone number id.

    Done by connect

  • Subscribing the WABA

    Connect subscribes the WABA to messages.

    Done by connect

  • Registering the phone

    Connect registers it with the 6-digit PIN.

    Done by connect

Events arrive flat and signed

Meta posts to /webhook. Watahub checks X-Hub-Signature-256, flattens Meta's envelope and forwards one signed delivery to your endpoint.

  • Messages

    text, image, audio, video, document, location, contacts, reaction, interactive

  • Echoes

    Replies sent from the WhatsApp Business app.

  • Statuses

    sent, delivered, read, failed

Check the signature with your secret and deduplicate on x-watahub-delivery-id.

Run it yourself

MIT. One operator: one Meta app, one subscriber webhook, one API key, and the lines you connect. You pay Meta's fees directly, with no markup.

  • Cloudflare Workers

    The gateway is its own Worker. This page is not that Worker.

  • Node

    Same routes. pnpm run dev:node.

  • One subscriber webhook

    Meta posts to /webhook; you get one signed, normalized delivery.

Terminal

$ git clone https://github.com/Hub-Ventures/watahub.git
$ cd watahub && pnpm install
$ pnpm run dev:node
$ curl http://localhost:3000/health

Or skip the Meta app

Create an account on app.watahub.dev and connect your numbers with Embedded Signup. The Meta token stays sealed in the gateway; you hold a Watahub API key you can revoke.

  • Inbox: read, reply and assign conversations.
  • Webhooks per number, signed with your secret.
  • Logs of API calls, Meta calls and deliveries, kept 7 days.
  • API keys shown once, revocable.
  • Installable on desktop and phone, with push notifications for new messages.
